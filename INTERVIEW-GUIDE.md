# Interview Guide — Windows Server & Active Directory

## 30-Second Explanation
This project demonstrates the core Windows infrastructure responsibilities I have practised in academic labs: Active Directory administration, DNS, DHCP, Group Policy, file permissions, PowerShell and structured troubleshooting. I organized the work as an enterprise-style environment so I can show not only configuration knowledge but also how the services depend on each other.

## Topics I Can Explain
- Why Active Directory depends heavily on DNS.
- How OUs and security groups serve different purposes.
- How Group Policy is applied and how I would troubleshoot it.
- How DHCP provides client addressing and what happens when it fails.
- How NTFS and share permissions affect effective access.
- How I would investigate an account lockout.
- How PowerShell can make repetitive administration more consistent.

## Troubleshooting Approach
I avoid changing multiple settings at once. I confirm the problem and scope, check dependencies, collect evidence, make the smallest justified change, verify the result and document what happened.
