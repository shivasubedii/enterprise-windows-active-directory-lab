# Evidence

This project is based on Windows Server and systems-administration work completed in academic lab environments by Shiva Subedi.

Genuine screenshots from the original lab are not currently available in this repository. No fabricated Windows screenshots are presented as evidence. Architecture diagrams and reconstructed troubleshooting scenarios should be clearly identified as portfolio documentation.

When original lab screenshots become available, recommended evidence includes:
- Server Manager / installed roles
- Active Directory Users and Computers OU structure
- DNS Manager
- DHCP scope/options
- Group Policy Management
- Mapped drive on a domain client
- NTFS/share permissions
- `gpresult`, `ipconfig`, or PowerShell validation output
